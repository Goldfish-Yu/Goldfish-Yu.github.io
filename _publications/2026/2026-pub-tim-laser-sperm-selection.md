abstract: >-
  This work presents a fully automated laser-assisted system for the selection of immotile
  sperm, enabling precise identification and viability testing using laser pulses. The system
  integrates real-time image analysis with robotic control to support intracytoplasmic sperm
  injection (ICSI) procedures where conventional motility-based selection is not applicable.
